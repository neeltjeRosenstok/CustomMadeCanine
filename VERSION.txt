The Custom Made Canine v21.7.11 ONLINE TEST

- Trainer can edit an existing course, including individual session dates, times, price, capacity, age limits and location.
- Trainer can delete a course only while it has no enrolment history.
- Course edits run the same booking/block/class conflict checks and exclude the course's own old sessions.
