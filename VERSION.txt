The Custom Made Canine v21.9.16i ONLINE TEST — Batch 1

Batch 1 changes:
- Appointment resource assignment now uses a searchable resource picker instead of numbered prompts.
- Add to calendar uses the native file share sheet where supported (including iPhone), with download fallback.
- Needs Attention order: reschedules first, refund/cancellation decisions second, payment verification next, new clients and vaccination below.
- Daily classes use the purple single left band and are clickable shortcuts to Scheduled Classes.
- No-refund class decisions require a client-facing note.
- Class edit Activity History records actual session/date/time changes and displays timestamps in Nairobi time.
- Client search filters the visible client list robustly.
- Trainer-proposed multi-session packages show Confirm & Pay and Refuse booking.
- Client financial notices show the latest three updates from the last 30 days, without the 30-day explanatory sentence.
- Inactive class cards are simplified.
- Class M-Pesa refund reference uses an uppercase, 10-character alphanumeric field.

Travel-buffer and first-available-slot scheduling changes are intentionally left for Batch 2.
No database reset is required.
